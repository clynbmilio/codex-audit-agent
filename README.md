# Immich API Reference via Sourcey

Community-generated documentation for the real
[Immich](https://github.com/immich-app/immich) open-source project. The static
reference is generated by Sourcey 3.6.3 from Immich's official OpenAPI
specification at commit
[`b24a617`](https://github.com/immich-app/immich/commit/b24a61714220a0c3999f4c24419b71472ee070c5).

This is an independent documentation build, not an official Immich deployment.

## Documentation Evidence

- Adapter: Sourcey OpenAPI
- Documented endpoints: 254
- Documented schemas: 373
- Exact source, commit, coverage totals, and page list: `/evidence.json`
- Searchable API reference: `/api.html`

Reproducible build command:

```powershell
Set-Location sourcey
npm.cmd install
npm.cmd run validate
npm.cmd run build
```
